#  Procesamiento de Aprendizaje Automático

##  Sobre este repositorio

Este repositorio reúne mis ejercicios y prácticas de la materia **Procesamiento de Aprendizaje Automático**, correspondiente a la Tecnicatura Superior en Ciencia de Datos e Inteligencia Artificial.

El objetivo es documentar mi aprendizaje, comprender cómo funcionan los algoritmos de Machine Learning y aprender a interpretar sus resultados.

##  Tecnologías utilizadas

- Python
- pandas y NumPy
- scikit-learn
- Matplotlib
- Jupyter Notebook
- MySQL

##  Aprendizaje supervisado

En el aprendizaje supervisado, los modelos aprenden a partir de datos donde conocemos la respuesta o variable objetivo.

### Algoritmos estudiados

**Árboles de decisión**

Construyen reglas mediante preguntas que permiten clasificar nuevos registros.

**K-Nearest Neighbors (KNN)**

Clasifica nuevos datos utilizando la información de sus vecinos más cercanos.

**Random Forest**

Combina múltiples árboles de decisión para obtener predicciones.

**Naive Bayes**

Utiliza probabilidades para determinar a qué clase es más probable que pertenezca un registro.

##  Evaluación de modelos

Durante las prácticas trabajé con:

- División de datos en entrenamiento y prueba.
- Validación cruzada.
- Accuracy, precision, recall y F1-score.
- Matrices de confusión.
- Comparación entre entrenamiento y prueba.
- Identificación de posibles problemas de overfitting.

##  Objetivo personal

Mi objetivo es comprender la lógica de cada algoritmo, practicar su implementación en Python y aprender a interpretar los resultados para resolver problemas utilizando datos.
